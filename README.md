# Cardputer 简谱演奏器

在 [M5Stack Cardputer-Adv](https://docs.m5stack.com/en/core/Cardputer-Adv) 的 56 键键盘上敲入简谱，回车演奏。谱子存在设备的 Flash 曲库里，断电不丢。

```
01                    1=C 4/4 120
3 3 3- 3 3 3- 3 5 1 2 3---
4 4 4 4 4 3 3 3 3 2 2 3 2-5-▌
11 notes 16 beats 8.0s
ENTER play  =setup  `back
```

为什么用简谱而不是五线谱：简谱是**首调**记谱法，`1` 唱 do 但具体是哪个音由开头的 `1=C` 决定。想换调只改这一处，整首歌跟着搬，旋律不变 —— 谱子其他地方一个字都不用动。

## 硬件

Cardputer-Adv（ESP32-S3FN8 / 8MB Flash）。音频走 ES8311 编解码 + NS4150B 功放 + 1W 喇叭。
非 Adv 的老款 Cardputer 理论上也能跑（`M5Cardputer` 库同时支持两者），但没测过。

## 编译烧写

只需要 [PlatformIO Core](https://docs.platformio.org/en/latest/core/installation/index.html)，不需要 VS Code：

```bash
brew install platformio          # 或 uv tool install platformio

pio run -t upload                # 编译 + 烧写
pio device monitor               # 看串口输出
pio test -e native               # 在电脑上跑单元测试（不需要设备）
```

工具链、ESP32 平台包和依赖库都由 `platformio.ini` 自动下载，首次约 330MB。

开发板要选 `esp32-s3-devkitc-1`（不是 `m5stack-*` 系列）—— 这是官方文档指定的。

## 简谱语法

### 头部行（第一行，可省略）

```
1=C 4/4 120
```

| 字段 | 含义 | 缺省 |
|---|---|---|
| `1=C` | 调号，决定 `1` 是哪个音。接受 `C C# D Eb E F F# G Ab A Bb B` | `1=C` |
| `4/4` | 拍号。**解析但忽略** —— 不画小节线，对发声无影响。保留只为抄谱时不报错 | `4/4` |
| `120` | 速度 BPM，真正决定快慢 | `120` |

### 音符

形式：`[#|b]` + `数字` + `[八度点…]` + `[时长修饰…]`

| 记号 | 含义 |
|---|---|
| `1`–`7` | 音级（do re mi fa sol la si） |
| `0` | 休止符 |
| `'` `,` | 高八度 / 低八度，可叠加（`1''` = 高两个八度） |
| `-` | 增时线，延长前一个音符一拍 |
| `/` | 减时线，时长减半，可叠加（`1//` = 1/4 拍） |
| `.` | 附点，时长 ×1.5 |
| `#` `b` | 升 / 降半音，写在数字**前面** |
| `\|` | 小节线，忽略（纯排版用） |

时长公式：`1 / 2^(斜杠数) × (有附点 ? 1.5 : 1) + 增时线个数`

| 输入 | 拍数 | |
|---|---|---|
| `1` | 1 | 中音 do |
| `1 -` / `1 - - -` | 2 / 4 | |
| `1.` | 1.5 | 附点 |
| `1/` / `1//` | 0.5 / 0.25 | 八分 / 十六分 |
| `1/.` | 0.75 | 附点八分 |
| `#1'/.` | 0.75 | 升高音do，附点八分（修饰符可叠） |

谱面解析失败时会精确报出错字符的下标，编辑器把它标红、拒绝播放 —— 不做「跳过错误继续播」，那样永远不知道哪里写错了。

## 按键

Cardputer 没有独立方向键。社区惯例的 `;`↑ `.`↓ `,`← `/`→ 与本语法的 `,`（低音点）`.`（附点）`/`（减时线）直接冲突，所以两个页面用不同的导航键 —— 编辑页只需要左右移光标，就用 `[` `]`（免 Shift、物理左右相邻、与语法零冲突）。

### 曲库页

| 键 | 作用 |
|---|---|
| `;` `.` | 上一首 / 下一首 |
| `⏎` | 打开编辑页 |
| `空格` | 直接播放（不进编辑页） |
| `n` | 新建一首 |
| `⌫` | 删除（按两次确认） |

### 编辑页

| 键 | 作用 |
|---|---|
| `1`-`7` `0` | 音级 / 休止符，**按下即试听** |
| `'` `,` `-` `/` `.` `#` `b` | 修饰符（`#` 是 Shift+3） |
| `空格` | 分隔音符 |
| `[` `]` | 光标左移 / 右移 |
| `fn` + `[` `]` | 跳行首 / 行尾 |
| `⌫` | 退格 |
| `⏎` | 播放；播放中再按停止 |
| `=` | 调号 / 速度设置 |
| `` ` `` | 存盘并返回曲库页 |

即时试听是**回看光标左边那个音符**，不是「按哪个数字响哪个音」。因为修饰符是后敲的：输入高音 do 的按键顺序是 `1` 然后 `'`，按下 `1` 的瞬间程序还不知道后面要跟 `'`。回看的做法让你先听到中音、敲完 `'` 再听到高音 —— 听到的是修正过程。

### 设置页

| 键 | 作用 |
|---|---|
| `[` `]` | 切换调号，**每切一下用新调号响一声 do** |
| `;` `.` | 速度 ±5 |
| `⏎` `` ` `` | 返回编辑页 |

## 项目结构

纯逻辑和硬件严格分开。`lib/` 下三个库零硬件依赖，所以能在电脑上跑单元测试，改语法规则不用烧板子：

```
lib/jianpu/     语法解析、音级→频率、播放时间轴
lib/texted/     光标算术、按音符边界折行
lib/songs/      10 首内置示例（含拍数对账）
src/main.cpp    应用状态机：曲库页 ↔ 编辑页 ↔ 设置页
src/player.cpp  非阻塞播放器
src/library.cpp LittleFS 曲库
test/           38 个用例，pio test -e native 约 2 秒跑完
```

曲库挂在分区表 `default_8MB.csv` 的 `spiffs` 分区（偏移 0x670000、1.5MB）。一首歌一个纯文本文件，**内容就是谱面原文，所见即所存** —— 以后要加 SD 卡导入导出或用电脑写谱，格式天然兼容。一首几百字节，够存几千首。

## 两个实测得出的约束

写在代码注释里，改动时别踩回去：

- **发声只占时长的 85%**，留 15% 静音间隙。否则连续相同的音（`3 3 3`）会粘成一个长音，听不出是三下。
- **播放器必须非阻塞**。用 `delay()` 的话播放期间整机锁死：按键无响应、不能中途停止。所以 `Player` 是个 `millis()` 驱动的状态机，主循环始终空着能读键盘。

## 加内置示例

往 `lib/songs/songs.cpp` 的数组里加一条，填上期望的音符数和总拍数：

```cpp
{
    "song-name",              // 中文名写注释里，标题用 ASCII（测试输出可读）
    "1=C 4/4 120",
    "3 3 4 5 5 4 3 2",
    8,                        // 期望音符数
    8.0f,                     // 期望总拍数
},
```

然后把 `src/main.cpp` 里的 `kSeedVersion` 加 1 —— 已经烧过旧固件的设备下次开机会自动补写新增的，**已有的不会重复添加**（按内容去重），**你删掉的示例也不会自己长回来**。

`pio test -e native` 会验证每首都解析得通、音符数和拍数对得上。手写转谱最容易漏空格、错符号、算错拍数，这个测试是兜底 —— 4/4 的 8 小节必须正好 32 拍。
