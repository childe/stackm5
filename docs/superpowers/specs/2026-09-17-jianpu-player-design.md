# Cardputer-Adv 简谱演奏器 · 设计文档

- 日期：2026-09-17
- 硬件：M5Stack Cardputer-Adv（ESP32-S3FN8 / 8MB Flash / 无 PSRAM）
- 工具链：PlatformIO Core 6.2.0，`platform = espressif32@7.1.3`，board `esp32-s3-devkitc-1`
- 已验证：编译、烧写、ES8311+喇叭发声、屏幕、键盘（见烟雾测试记录）

## 1. 目标

在 Cardputer-Adv 上用它自带的 56 键键盘**现场敲入简谱文本**，回车即演奏。谱子存在
Flash 曲库里，可存多首，开机恢复。

### 明确不做（YAGNI）

| 不做 | 理由 |
|---|---|
| 三连音、连音线、反复记号 | 语法范围定在「常用集」，这些用得少、解析复杂 |
| 和弦 / 多声道 | 1W 单声道喇叭放和弦意义不大 |
| SD 卡读写 | 硬件支持，但当前不需要。文件格式是纯文本，以后要加是白送的 |
| 歌名中文输入 | 56 键小键盘上敲中文是苦差事，改用「编号 + 谱面预览」认歌 |
| 小节线 `|` 的语义 | 对发声无影响。但**解析器必须容忍并忽略它**，这样从网上抄谱不会报错 |

## 2. 语法规范

### 2.1 头部行（第一行，可省略）

```
1=C 4/4 120
```

| 字段 | 作用 | 缺省 |
|---|---|---|
| `1=C` | 调号。接受 `C C# Db D Eb E F F# Gb G Ab A Bb B` | `1=C` |
| `4/4` | 拍号。**解析但忽略**（不画小节线，对发声无影响）。保留只为抄谱时不报错 | `4/4` |
| `120` | 速度 BPM | `120` |

### 2.2 音符

形式：`[#|b]` + `数字` + `[八度点…]` + `[时长修饰…]`

| 位置 | 记号 | 含义 |
|---|---|---|
| 前缀 | `#` `b` | 升 / 降半音 |
| 主体 | `1`–`7` | 音级；`0` = 休止符 |
| 八度 | `'` | 高八度，可叠加 |
| 八度 | `,` | 低八度，可叠加 |
| 时长 | `/` | 减半，可叠加 |
| 时长 | `.` | 附点，×1.5 |

**增时线 `-` 是独立 token**，把前一个音符延长一拍。开头就出现 `-`（前面没有音符）是错误。

**时长公式**

```
beats = 1 / 2^(斜杠数) × (有附点 ? 1.5 : 1) + 增时线个数
```

| 输入 | 拍数 |
|---|---|
| `1` | 1 |
| `1 -` / `1 - - -` | 2 / 4 |
| `1.` | 1.5 |
| `1/` / `1//` | 0.5 / 0.25 |
| `1/.` | 0.75 |
| `#1'/.` | 0.75（升 + 高八度 + 附点八分） |

**分隔符**：空格、换行、`|`（忽略）。

### 2.3 音级 → 频率

`1=C` 时中音 `1` = C4 = 261.626Hz。大调音阶各级距主音的半音数：

```
1→0  2→2  3→4  4→5  5→7  6→9  7→11
```

```
freq = 261.626 × 2^((semitone[step] + accidental + 12×octave + keyRoot) / 12)
```

（这段公式已在烟雾测试里听感验证过。）

### 2.4 错误处理

解析器返回**第一个出错字符的下标 + 原因**。编辑器把该字符标红、光标跳过去、拒绝播放。
不做「跳过错误继续播」——那样用户永远不知道哪里写错了。

需要报错的情况：未知字符、`8`/`9`、开头的 `-`、`#`/`b` 后面不是数字、调号写错。

## 3. 键盘操作

Cardputer 没有独立方向键。社区惯例 `;`↑ `.`↓ `,`← `/`→ 与本语法的 `,`（低音点）
`.`（附点）`/`（减时线）**直接冲突**。解决办法：两个界面用不同导航键。

### 3.1 曲库页（开机停在这里，无简谱输入，不冲突）

```
;  上一首        .  下一首
⏎  打开编辑      ␣  直接播放
n  新建          ⌫  删除（按两次确认）
```

### 3.2 编辑页

```
1-7 0     输入音级（同时立即试听 —— 阶段 4）
' , - / . 修饰符
b         降号（升号用 shift+3 打出 #）
␣         分隔音符
[  ]      ← → 移动光标
fn + [ ]  行首 / 行尾
⌫         退格
⏎         播放整首（播放中再按 ⏎ 停止）
=         打开头部设置（调号 / 速度）
`         返回曲库页
```

用 `[` `]` 当左右键的理由：免 Shift、物理左右相邻、形状自带方向含义、**与语法零冲突**。

### 3.3 头部设置小窗

```
[  ]  切换调号
;  .  BPM ±5
⏎ 或 `  返回编辑页
```

## 4. 界面布局

屏幕 240×135（`setRotation(1)`）。Font2 约 8px 宽 / 16px 高 → 每行 ~30 字符，共 8 行。

### 曲库页

```
┌──────────────────────────────┐
│ LIBRARY            3 songs   │
├──────────────────────────────┤
│ ▶ 01  3 3 3- 3 3 3- 3 5 1 2  │
│   02  1 1 5 5 6 6 5 -        │
│   03  3 3 4 5 5 4 3 2        │
├──────────────────────────────┤
│ ;↑ .↓  ⏎edit ␣play  n new    │
└──────────────────────────────┘
```

### 编辑页

```
┌──────────────────────────────┐
│ 01            1=C 4/4 120    │
├──────────────────────────────┤
│ 3 3 3- 3 3 3- 3 5 1 2 3---   │
│ 4 4 4 4 4 3 3 3 3 2 2 3 2-5-▌│
├──────────────────────────────┤
│ 25 notes · 32 beats · 16.0s  │
│ ⏎play  [ ]cursor  `back      │
```

- **自动折行按音符边界折**，不把 `3---` 或 `#1'` 拆到两行
- **播放时**：正在响的音符反色高亮，底部统计行换成进度条

## 5. 模块划分

```
lib/jianpu/          纯 C++，零硬件依赖 → 可在 Mac 上单元测试
  jianpu.h
  jianpu.cpp
src/
  main.cpp           应用状态机：曲库页 ↔ 编辑页 ↔ 头部设置
  player.h/.cpp      非阻塞播放器
  library.h/.cpp     LittleFS 曲库
  editor.h/.cpp      文本缓冲 + 光标 + 折行
  ui.h/.cpp          两个界面的绘制
test/test_jianpu/
  test_main.cpp      Unity 测试用例
```

### 5.1 `lib/jianpu` 接口

```cpp
namespace jianpu {

struct Note {
    uint8_t  step;        // 1-7；0 = 休止符
    int8_t   octave;      // 相对中音的八度偏移
    int8_t   accidental;  // -1 降 / 0 本位 / +1 升
    float    beats;
    uint16_t srcPos;      // 在原文中的起始下标（播放高亮、错误定位都要用）
    uint16_t srcLen;
};

struct Header {
    int8_t keyRoot = 0;   // 调号主音相对 C 的半音数：C=0 D=2 F=5 …
    int    bpm     = 120;
};

struct ParseError {
    bool        ok     = true;
    uint16_t    pos    = 0;
    const char* reason = "";
};

struct Score {
    Header            header;
    std::vector<Note> notes;
    ParseError        error;
    float totalBeats() const;
};

Score parse(const char* text, size_t len);
float noteToFreq(const Note& n, const Header& h);

}  // namespace jianpu
```

`srcPos` / `srcLen` 是关键设计：播放时要靠它高亮原文里对应的字符，报错时要靠它定位。

### 5.2 数据流

```
键盘 → editor（字符串缓冲）
         │
         ├─（按 ⏎）→ jianpu::parse() → Score
         │                               ├─ error → ui 标红，不播放
         │                               └─ ok    → player.start(score)
         │
         └─（1.5s 无操作）→ library.save() → LittleFS
```

## 6. 播放器：为什么必须非阻塞

烟雾测试用了 `delay()`，播放那 16 秒整个设备锁死：按键无响应，不能中途停止。
真 app 必须做成状态机：

```cpp
class Player {
public:
    void start(const jianpu::Score& score);
    void stop();
    void update();               // 每次 loop() 调一次
    bool isPlaying() const;
    int  currentIndex() const;   // 供 UI 高亮
private:
    uint32_t _nextNoteAtMs;
};
```

`update()` 比较 `millis() >= _nextNoteAtMs`，到点就 `Speaker.tone()` 下一个音并推进时间戳。
主循环始终能读键盘 → 播放中可以按 `⏎` 停止、能看到高亮走动。

**发声时长取 85%**，留 15% 静音间隙。否则连续相同音（如 `3 3 3`）会粘成一个长音。
（这条在烟雾测试里验证过效果。）

## 7. 存储

LittleFS 挂在分区表 `default_8MB.csv` 的 `spiffs` 分区（偏移 0x670000，**1.5MB**）。
`platformio.ini` 需加 `board_build.filesystem = littlefs`。

一首歌一个文件，**内容就是谱面原文，所见即所存**：

```
/songs/01.jp
/songs/02.jp
```

```
1=C 4/4 120
3 3 3- 3 3 3- 3 5 1 2 3---
```

纯文本的好处：以后加 SD 卡导入导出、或用电脑写谱，格式天然兼容。一首几百字节 →
1.5MB 够存几千首。

**自动保存有防抖**：编辑页按键后**延迟 1.5 秒无操作**才写盘。Flash 有擦写寿命，
不能每敲一个字符就擦写一次。

## 8. 测试策略

`platformio.ini` 增加第二个环境：

```ini
[env:native]
platform = native
test_framework = unity
build_flags = -std=gnu++17
```

`pio test -e native` 只编译 `lib/jianpu` + `test/`，不碰 Arduino，**1 秒出结果**。

覆盖清单：

- 各时长记号单独：`1` `1-` `1.` `1/` `1//` `1/.`
- 增时线并入前音：`3 - - -` → 1 个音符、4 拍
- 八度叠加：`1'` `1''` `1,` `1,,`
- 升降号：`#4` `b7`
- 修饰符组合：`#1'/.`
- 休止符 `0`
- 分隔符容错：多个空格、换行、`|`
- 调号：`1=F` 下 `1` 的频率 = F4（349.23Hz）
- 头部缺省（不写头部行时按 `1=C 4/4 120`）
- 错误定位：未知字符、`8`、开头的 `-`、`#` 后无数字、调号写错

| 阶段 | 内容 | 产出 |
|---|---|---|
| **1** | TDD 写 `lib/jianpu` 解析器，`pio test -e native` 全绿 | 一个经过测试的解析器，在 Mac 上就能看到结果 |
