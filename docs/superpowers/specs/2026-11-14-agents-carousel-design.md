# AGENTS 走马灯视图和筛选 — Design（小改动）

接 `2026-11-14-agents-app-design.md`。只改 Cardputer 端，Mac 端协议不变。

## 需求（用户）

- 新增走马灯视图：一屏一个 session，每秒换下一个。卡片只显示**状态符号（转圈 / ✳）和标题**
- 一个键切换显示范围：只看「该你了」/ 全部
- 一个键在走马灯和列表之间切换
- 空格在键盘右下角，用来跳转；切换视图换别的键

## 方案

只有一种合理做法：筛选和轮换都在 Cardputer 本地做，Mac 每 2 秒推的完整列表里已经有状态。
（另一种是让 Mac 端按筛选推不同列表 —— 要改协议、切换筛选要等一轮推送，没有好处，不选。）

## 设计

| 键 | 作用 |
|---|---|
| 空格 / ENT | 跳到当前显示的 session（列表里是光标行，走马灯里是当前卡片） |
| `v` | 切换视图：走马灯 / 列表 |
| `f` | 切换筛选：只看「该你了」/ 全部 |
| `;` `.` | 上一个 / 下一个；走马灯里同时暂停自动轮换 10 秒（比一格长） |
| `` ` `` | 回菜单 |

走马灯画面：

```
AGENTS        ● Mac   该你了 2/3
 ✳  电路图项目增加
    题目
SPC 跳转  v 列表  f 全部
```

- 大号状态符号 + 大号中文标题（`efontCN_24`，放不下就用 14 号字 2 倍放大），最多折 3 行，再长截断加 `…`
- 顶栏右侧：当前筛选名 + 位置 `i/n`
- 每 5000ms 前进一个（初版 1000ms，实机太快读不完，用户改成 5 秒），到末尾回到第一个；自动前进**不**清 `!` 标记（只有手动选中 / 跳转才清）

规则（我的决定，用户可改）：

- 筛选对两种视图都生效；光标 / 当前卡片只在可见的 session 里移动
- 首次进页面默认 走马灯 + 只看「该你了」；切换后的选择存在 RAM（静态变量），重启恢复默认
- 只看「该你了」时一个都没有：显示「都在跑（N 个）」
- 提醒触发：当前项跳到触发的 session（它一定是「该你了」，两种筛选下都可见），走马灯在它上面停 10 秒；响铃闪屏照旧
- 切换筛选时，当前 session 仍可见就留在它上面，否则留在原位置（越界钳到末尾）

## 实现要点

- `lib/agents`：`Model` 加筛选（默认 All，保持现有测试语义），光标改为在可见列表上的下标；
  加不清标记的循环前进 `advance()`；加纯时间逻辑 `Rotation`（到点前进、hold 暂停），全部 native 单测
- `src/agents_app.cpp`：加走马灯绘制、`v` / `f` / 空格按键；README 更新按键表和画面
